Formatos aceptados: Excel 2007+ (.xlsx) o Excel 97-2003 (.xls)

ℹ️ Formato Esperado

El archivo Excel debe contener las siguientes columnas (no importa el orden):

  • RFQ o PEDIDO o Request # — Número de solicitud (obligatorio)
  • DESCRIPCION — Descripción de la solicitud
  • SOLICITANTE — Nombre del solicitante
  • PLANTA — Planta de destino (Tenango o MAQ RA)
  • PROYECTO o Clave del proyecto o Numero de CapEx — Clave CAPEX

Nota: Las columnas adicionales (COMPARATIVA, PROVEEDOR SELECCIONADO, #OC, fechas, etc.) son opcionales y se importarán si están disponibles.

🔍 Proceso de Importación

  1. Vista Previa: Primero verá un resumen de los datos detectados.
  2. Validación: El sistema identificará RFQ nuevos, actualizaciones y duplicados.
  3. Confirmación: Deberá confirmar antes de que se guarden los cambios en la base de datos.

Importante: Los RFQ existentes con el mismo número se actualizarán con la nueva información. No se crearán duplicados.
